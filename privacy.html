Privacy Policy — 매일 쑈핑! 매쑈! upload tool

This is a personal tool used only by the owner of the YouTube channel "매일 쑈핑! 매쑈!". It is not offered to the public and has no other users.

What the tool accesses

With the owner's explicit consent (Google OAuth), the tool uses the YouTube Data API and the YouTube Analytics API to (1) upload the owner's own videos to the owner's own channel and set their title, description, visibility and scheduled publish time, (2) read the basic information of the connected channel (channel ID and title) to confirm that the correct channel is connected, (3) read the view counts and watch-time statistics of the owner's own videos, (4) change the scheduled publish time or visibility of the owner's own videos, and (5) post one information comment on the owner's own videos and read the comments on them.

What we collect and store

  • We do not collect or share any personal data of viewers or subscribers. Public comments on the owner's own videos (display name and comment text) are shown only on the owner's own computer so the owner can answer them, and are not published or shared.
  • We never receive or store the owner's Google password.
  • The OAuth access token is stored only on the owner's own computer and is never published or sent to anyone else.

Sharing

We do not sell, share or transfer Google user data to any third party. Data obtained through the YouTube API is used only for the purposes described above.

Retention and revoking access

The token can be deleted from the owner's computer at any time. Access can be revoked at any time at https://myaccount.google.com/permissions.

YouTube API Services

The tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. The Google Privacy Policy applies.

Contact

Please contact the channel owner through the YouTube channel page.
